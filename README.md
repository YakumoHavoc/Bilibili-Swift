# 哔哩哔哩 macOS 客户端（SwiftUI 复刻）

用 Swift + SwiftUI 原生复刻的哔哩哔哩桌面客户端，覆盖首页、热门、番剧、影视、直播、动态、搜索、UP 主空间、排行榜、我的等主要页面，并内置视频播放器、弹幕、视频下载与直播录制。

当前版本：**1.0**

## 功能特性

### 内容浏览
- 首页推荐流、热门、排行榜
- 番剧 / 影视（PGC）列表与剧集播放
- 直播列表与直播间播放
- 搜索（综合、视频、用户等）
- UP 主空间：投稿、动态等
- 动态页：关注的 UP 主动态、图片查看原图、转发动态详情与评论、评论表情与配图

### 账号
- 扫码登录，登录态本地持久化
- 我的页：收藏、历史记录、稍后再看

### 播放器
- 基于 AVPlayer 的视频播放，支持 DASH 音视频自动合成
- 按视频源支持高清画质：1080P / 1080P+ / 1080P60 / 4K / HDR / 杜比视界 / 8K
- 支持 Hi-Res 无损与杜比全景声音轨，控制栏显示当前音质
- 弹幕引擎（滚动弹幕、按颜色/时间轴渲染）
- 直播弹幕（WebSocket 实时接收）
- 清晰度切换、倍速播放、分 P 切换、全屏
- 空格键与键盘播放/暂停媒体键控制播放
- 播放前的音频设备预热，避免首次播放声音延迟

### 直播
- 直播间画质选择（按房间实际支持范围，取最高可用画质）
- 直播录制：抓取 HLS 分片落盘，同时记录弹幕时间轴
- 录制结束后自动转封装为 MP4，弹幕与元数据单独保存
- 录制内容可在播放器内回放，回放时弹幕按原时间轴同步显示
- 独立的「录制」页面：回放、在 Finder 中显示、删除、打开录制目录

### 视频下载
- 播放器控制栏内按清晰度下载当前分 P（普通视频与番剧均支持）
- 与 bilibili-helper 相同的思路：拉取 DASH 音视频分离流后合成 MP4
- 优先 H.264 + AAC，下载完成直接封装，无需重新编码
- 下载失败自动回退官方单文件 MP4
- 下载页可查看进度、取消任务、在 Finder 中显示
- 每个视频与直播录制各占一个独立文件夹，内含媒体文件、`danmaku.json` 弹幕与 `meta.json` 元数据
- 启动时自动扫描下载目录与录制目录，迁移文件夹后仍可在应用内看到

## 存储位置

```
~/Downloads/哔哩哔哩/
├── <视频标题>_<时间戳>/           # 视频下载
│   ├── video.mp4
│   ├── danmaku.json
│   └── meta.json
└── 直播录制/
    └── <直播标题>_<时间戳>/       # 直播录制
        ├── recording.mp4          # 转封装完成（未完成时为 recording.ts）
        ├── danmaku.json
        └── meta.json
```

下载与录制默认保存在同一个「下载」目录下，但分属不同文件夹，应用内也分为「下载」与「录制」两个独立页面管理。

## 系统要求

- macOS 14.0 及以上
- Xcode 15 及以上（使用 Xcode 26 SDK 亦可构建）

## 构建与运行

```bash
xcodebuild -project Bilibili.xcodeproj \
  -scheme Bilibili \
  -configuration Debug \
  -derivedDataPath build \
  CODE_SIGNING_ALLOWED=NO \
  OTHER_SWIFT_FLAGS='$(inherited) -disable-sandbox' \
  build
```

运行：

```bash
open build/Build/Products/Debug/Bilibili.app
```

也可以直接用 Xcode 打开 `Bilibili.xcodeproj` 运行。

## 目录结构

```
Bilibili/
├── App/            # 应用入口、AppDelegate、全局状态
├── Core/           # 网络层、登录、模型、工具、音频预热、下载与直播录制管理
├── Player/         # 播放器窗口、播放逻辑、弹幕引擎、直播弹幕
├── UI/             # 各页面与通用组件、主题
├── Assets 图标      # AppIcon.icns
└── Info.plist
```
